Step 1: Checking Node.js and npm
Node.js and npm were checked using node -v and npm -v commands. Both are installed and working correctly on the system
<img width="263" height="74" alt="2" src="https://github.com/user-attachments/assets/4f8b5f10-cc0a-4cf2-82f8-112afc2e0bc2" />

Step 2: Creating the Project Folder
A folder named node-server-demo was created to store the Node.js server project files. The terminal was then moved into this folder
<img width="355" height="208" alt="3" src="https://github.com/user-attachments/assets/b1168b7f-83dd-496f-81a9-f7f5e973ff64" />

Step 3: Initializing the Node.js Project
The npm init -y command was used to initialize the Node.js project. It automatically created a package.json file containing the project configuration.
<img width="328" height="81" alt="4" src="https://github.com/user-attachments/assets/9612715c-6172-4990-b9f8-778292412f21" />

Step 4: Creating server.js
A server.js file was created using Node.js HTTP module. The server is configured to listen on port 3000 and return an HTML heading containing "Hello Javascript".
<img width="416" height="140" alt="5" src="https://github.com/user-attachments/assets/e807c923-2849-4552-a90b-a9451fe3dcdf" />

Step 5: Testing the Server in Browser
The server was tested by opening http://localhost:3000 in a web browser. The page successfully displayed "Hello Javascript", confirming that the Node.js server is working.
<img width="660" height="361" alt="6" src="https://github.com/user-attachments/assets/ad44cd69-73a6-4478-906f-e2cafc4a4e48" />

Step 6: Stopping the Server
The running Node.js server was stopped by pressing Ctrl + C in the terminal.
